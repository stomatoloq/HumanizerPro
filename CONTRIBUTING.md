# Contributing Guide

Thank you for your interest in contributing to **`stylometric-de-ai-rewriter`**! This open-source repository maintains a universal, zero-dependency LLM skill for stripping multi-vendor AI provenance artifacts (**Layer A**) and neutralizing 38 universal LLM stylistic signatures (**Layer B**) across languages and genres.

---

## 🛠️ Ways to Contribute

1. **Cross-Linguistic Morphosyntactic Patterns:** Add language-specific manifestations of universal LLM habits (such as calqued copulas, negative parallelisms, or stacked non-finite verb chains in analytic, agglutinative, fusional, or logographic languages).
2. **Layer A Provenance Updates:** Document new invisible Unicode codepoints, exotic whitespace tokens, citation brackets, or URL tracking parameters introduced by LLM web interfaces.
3. **Documentation & Examples:** Improve visual clarity, accessibility, or before/after test cases in `README.md`, `docs/readme.html`, and `docs/rules.html`.
